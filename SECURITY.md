# Security policy

Keystone Quarry is a game that runs entirely on the player's device. It has no accounts or servers, and it collects no data. Progress is saved only in the player's own browser or app.

If you find a security problem, such as a way for the desktop app to run code it shouldn't or to load content from the network, please report it privately:

**[Report a vulnerability](https://github.com/git-cgallagher/keystone-quarry/security/advisories/new)**

Please don't open a public issue for security problems. You'll get a reply within a week.
